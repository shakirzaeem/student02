Careers and Professional Certifications

If you like AI, there are many ways to work with it. These are three roles I found interesting.

Career options

CareerWhat they doHelpful certifications / pathways
Machine Learning EngineerBuilds and deploys models that learn from dataGoogle Professional Machine Learning Engineer; AWS Certified Machine Learning - Specialty
Data ScientistAnalyses data and explains what it meansIBM Data Science Professional Certificate; Microsoft Azure Data Scientist Associate
AI EngineerAdds AI features to apps and servicesMicrosoft Azure AI Engineer Associate; Google Cloud Skills Boost paths

Where to start

  1. Learn basic Python and statistics.
  2. Build two or three small projects.
  3. Pick one certificate that matches the job you want.

Certificate names and exam details change, so check each provider's official page before you sign up.
