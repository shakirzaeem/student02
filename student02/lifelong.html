Lifelong Learning

My independent learning journey

What I learned: I learned the difference between AI, machine learning and generative AI. I also learned how to write clearer questions so tools give better answers.

Why it matters: AI is showing up in almost every job. Knowing the basics helps me use it wisely instead of just copying what it says.

New skills: researching from several sources, checking facts, and building a website with only HTML and CSS.

What I want to learn next: basic Python and how machine learning models are trained.

My plan: finish one short online course each trimester break and try a small beginner project.

Reflection: Learning on my own was harder than I expected because nobody tells you what to do next. But it felt good to figure things out. I now trust myself more to learn a new topic from scratch.
